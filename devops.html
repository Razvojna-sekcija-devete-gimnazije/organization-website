DevOps & Infrastructure

DevOps predstavlja skup praksi koje povezuju razvoj softvera i administraciju servera. Cilj je automatizacija build-a, deployment-a i održavanja sistema.

Docker

Kontejnerizacija aplikacija omogućava jednostavno pokretanje sistema na bilo kom serveru bez komplikovane konfiguracije.

Linux Serveri

Učenici rade sa Linux terminalom, SSH konekcijama, procesima i osnovama serverske administracije.

CI/CD Pipeline

Automatizacija testiranja i deployment-a aplikacije pomoću GitHub Actions workflow-a.
