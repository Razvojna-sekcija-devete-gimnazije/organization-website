Roadmap Sekcije

Program sekcije organizovan je kao višefazni razvojni proces. Svaka faza predstavlja deo stvarnog software engineering workflow-a.

FAZA I — Software Engineering Foundations

Git, GitHub, Scrum, Jira, Confluence, osnove web arhitekture, HTTP protokol, REST API koncepti i organizacija softverskih timova.

FAZA II — Backend Engineering

Quarkus framework, Java 21, PostgreSQL, Hibernate ORM, JWT autentifikacija, API development i sigurnost sistema.

FAZA III — Frontend Engineering

React, TypeScript, SPA arhitektura, routing, state management i UI/UX dizajn.

FAZA IV — DevOps & Deployment

Docker, Linux serveri, deployment pipeline, GitHub Actions i hosting aplikacije.

FAZA V — Finalna prezentacija

Javna demonstracija sistema, retrospektiva projekta i analiza procesa razvoja.
