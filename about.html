Cilj Sekcije

Cilj sekcije nije samo učenje pojedinačnih tehnologija. Cilj je simulacija rada pravog softverskog tima i upoznavanje učenika sa kompletnim procesom razvoja modernih aplikacija.

Realan razvoj softvera

Učenici prolaze kroz iste faze kroz koje prolaze profesionalni razvojni timovi: planiranje projekta, razvoj arhitekture, implementaciju funkcionalnosti, testiranje, debugging i deployment.

Timski rad

Svaki član sekcije učestvuje u radu tima kroz sprintove, taskove, code review procese i zajedničko rešavanje problema.

Inženjerski pristup

Fokus sekcije je na razumevanju kako sistemi funkcionišu, a ne samo na pisanju koda.

Šta učenici uče?

Projektovanje sistema

Učenici uče kako se planiraju aplikacije, definišu zahtevi, organizuje baza podataka i projektuje arhitektura sistema.

Backend razvoj

Razvoj serverske logike, API sistema, autentifikacije, autorizacije i komunikacije sa bazom podataka.

Frontend razvoj

Razvoj korisničkih interfejsa, React aplikacija, navigacije, formi i interakcije sa backend sistemom.

DevOps

Docker kontejneri, deployment aplikacija, Linux serveri i automatizacija build procesa.
